# CubeMap Framework - Cloud Exploit & Recon Target System

An advanced reconnaissance framework leveraging high-speed native C++ logic interfaces linked to an automated Python execution pipeline. It provides targeted enumeration parameters alongside an interactive post-exploitation console shell architecture.

## Global Installation & Setup
Run the framework initialization wrapper script using root permissions to automatically link binaries directly into system executables paths:

sudo chmod +x setup.sh
sudo ./setup.sh


## Global Execution Flow
Once successfully initialized, execution parameters map out system domains globally from any active path console prompt:

CubeMap -e aws-azure-gcp targetedbank


## Interactive Command Parameters
If active vectors are mapped, the environment drops down directly into a local operational workspace CLI:
* **use <id>**: Focus context structures targeting selected vulnerabilities mappings (e.g. `use aws-1`).
* **exploit**: Pass runtime controls execution parameters down to inline assembly injection engines payloads.
* **exit**: Shut down execution frameworks interfaces.
